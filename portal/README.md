# SWRV Client Portal

Client portal for SWRV On The Go. Supabase auth (email + Google), Postgres with RLS, 4 sections: My Visions, My Projects, Billing, Account. Roles: client / admin / partner.

## Deploy (Cloudflare Pages)
- Root directory: `portal`
- Build command: `npm install && npm run build`
- Build output directory: `dist`
- Custom domain: `app.swrvonthego.pro`

## Stack
React + TypeScript + Vite, Supabase (project `jbnwpgvzyykqyqagzcjt`).
