How to edit one

  1. Download the intro (it's a single .html file).
  2. Open it in any text editor and find the lines marked EDIT: — change the title, subtitle, and eyebrow text.
  3. Swap the colors at the top (--gold, --bg, etc.) for a new vibe.
  4. Drop it into a website as the landing page. It plays once, then reveals the site. Works on every browser and phone — no plugin.
